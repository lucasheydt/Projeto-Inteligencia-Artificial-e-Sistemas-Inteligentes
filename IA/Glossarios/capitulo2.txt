GLOSSÁRIO TÉCNICO - CAPÍTULO 2

Token
Tradução: Token (ou Símbolo)
Definição: A menor unidade de texto (palavra, subpalavra ou caractere) resultante da fragmentação de um texto bruto.
Função no LLM: Serve como a unidade básica de entrada que o modelo aprenderá a processar e prever.
Relação: É mapeado para um Token ID numérico através do Vocabulário.
Exemplo: A frase "Olá, mundo" pode ser dividida nos tokens ["Olá", ",", "mundo"].

Byte Pair Encoding (BPE)
Tradução: Codificação de Pares de Bytes
Definição: Um algoritmo de tokenização que constrói um vocabulário fundindo iterativamente os caracteres ou subpalavras mais frequentes.
Função no LLM: Permite que o modelo processe qualquer palavra desconhecida (fora do vocabulário), dividindo-a em fragmentos ou caracteres individuais.
Relação: Substitui a necessidade de tokens especiais de erro (como <|unk|>) em modelos modernos como o GPT.
Exemplo: A palavra "incomum" pode ser quebrada nos sub-tokens BPE ["in", "comum"].

Word Embeddings
Tradução: Embeddings de Palavras (ou Representações Vetoriais Contínuas)
Definição: Uma matriz onde cada Token ID é projetado em um espaço vetorial contínuo de alta dimensão.
Função no LLM: Converte dados discretos (números inteiros) em um formato numérico rico que a rede neural consegue processar, capturando relações semânticas.
Relação: Recebe os Token IDs e, posteriormente, é somado aos Positional Embeddings antes de entrar no mecanismo de atenção.
Exemplo: O Token ID 5 sendo transformado em um vetor de 256 dimensões como [0.12, -0.45, ..., 0.89].
